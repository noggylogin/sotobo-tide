# SOTOBŌ TIDE v2 — 外房タイドグラフ

スマホ / PC用の静的Webアプリです。GitHub Pagesで公開できます。

## 改良内容

- 「いすみ川河口」等は、近隣港「上総勝浦」の潮汐推算を優先して表示します。これは河口の実測潮位でもタイドグラフBIの公式データでもありません。
- 潮汐APIが利用できない場合はOpen-Meteo Marineの**平均海面基準（MSL）**モデル値を表示し、画面にその旨を明記します。MSLの値を潮位表基準の値と混同しないでください。
- 風は海上位置に対する気象庁 MSM（Open-Meteo経由）を取得し、モデルが提供する時間帯だけ優先表示。それ以外の風・気温・雨はOpen-Meteo天気予報です。
- 波高・周期・水温はOpen-Meteo Marine。3時間ごとの風速・風向・波高・気温・雨量テーブルも表示します。
- 他の海域ポイントも選択可能。

### データソース／ご注意

- 潮位：tide736.net 公開API `https://api.tide736.net/get_tide.php`（ポート選択に対応）。**外部APIのCORS制限等により、GitHub Pagesから直接取得できない場合があります。** この場合はMSLモデルに切り替わるため、海面水位が全く別の数字になります。利用先の公開条件やリクエスト制限も確認してください。
- 風：Open-Meteo JMA API `https://api.open-meteo.com/v1/jma` の JMA MSM。BI側の気象データを直接取得しているわけではありません。
- 海面水位・波：Open-Meteo Marine。
- 最新の潮汐表や安全判断は海上保安庁等の公式情報で確認してください。

### BIと並べて比較した例（2026年10月20日）

|  | BI夷隅川河口 | tide736上総勝浦 |
|---|---|---|
| 朝の干潮 | 05:29 / 51cm | 05:35 / 55.3cm |
| 昼の満潮 | 13:40 / 120cm | 13:38 / 125.0cm |
| 夜の干潮 | 19:19 / 98cm | 19:21 / 101.5cm |
| 夜の満潮 | 23:19 / 107cm | 23:38 / 112.3cm |

同一値を保証するものではありません。

## GitHub Pagesへの更新方法

既存のリポジトリで **Add file → Upload files** を選び、このフォルダの `index.html`、`app.js`、`sw.js`、`icon.svg`、`manifest.webmanifest`、`README.md` をアップロードして置換します。変更をコミットしてからサイトを再読み込みしてください。古い表示が残るときは再読み込みまたはキャッシュをクリアしてください。
